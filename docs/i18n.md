# Internationalization: API, conventions and frozen identifiers

English is the default language; Brazilian Portuguese (`pt-BR`) is selectable. The server never
emits display text (see `docs/contract.md`); every string the user reads comes from the browser
dictionaries in `public/i18n/`.

## Module API (`public/i18n/index.js`)

```js
export async function initI18n();          // loads /api/config, resolves the locale, loads the dictionaries,
                                           // builds `fmt`, sets <html lang>, document.title and data-i18n nodes.
                                           // Pages await this before rendering anything.
export const config;                       // the /api/config object (appName, locale, timeZone, utcOffset, floorTokens, start, features…)
export let locale;                         // 'en' | 'pt-BR'
export function t(key, params);            // dictionary value: string with {x} placeholders, or a function (params) => string
export function plural(n, key, params);    // value is { zero?, one, other }; n === 0 → zero ?? other; else Intl.PluralRules.
                                           // Callers pass the number AS DISPLAYED (already rounded). params.n defaults to fmt.int(n)
export const fmt;                          // formatters (below), built with { locale, timeZone }
export function applyStatic(root = document); // data-i18n (textContent), data-i18n-html (innerHTML), data-i18n-title,
                                           // data-i18n-placeholder, data-i18n-aria
export function setLocale(code);           // localStorage.lang = code; removes ?lang from the URL; location.reload()
export function cityLabel(city);           // city.name ?? t('city.unnamed', { code })
export function displayName(person);       // { full, short }: nickname/pretty name, or the anonymized name built from
                                           // t('anon.animals')[animal], t('anon.adjectives')[adjective] and n.
                                           // `short` is the first name, or the animal for anonymized people (in both languages)
export async function loadPartial(name);   // fetches public/i18n/<locale>/<name>.html (help panes), falls back to en
```

Locale resolution, in order: `?lang=` → `localStorage.lang` → `config.locale` →
`navigator.language` (`pt*` → `pt-BR`, anything else → `en`). Unknown values fall back to `en`.

Changing the language reloads the page. Nothing re-renders live, so no module needs a locale hook;
every visible string is rebuilt from `state`/`data` on load and the pages are served `no-store`.

Missing key: fall back to the English dictionary, then return the key itself and log
`console.warn('[i18n] missing', key)` once per key. The verification step greps the console for it.

## Dictionaries

```
public/i18n/
  index.js            API above
  fmt.js              formatters
  en/common.js        shared: city.unnamed, anon.*, badge.*, belt.*, model.*, period.*, error.*, nav, switcher
  en/city.js          runtime strings of the city (panels, toasts, newspaper, signs, link builder, timeline)
  en/city-static.js   data-i18n strings of city.html (legend, buttons, titles)
  en/climb.js         runtime strings of the climb (HUD, board, plaques, card, ruler, ticker)
  en/climb-static.js  data-i18n strings of climb.html
  en/help-city.html   help modal panes (HTML partial, fetched when the modal opens)
  en/help-climb.html
  pt-BR/…             same files
```
Each `.js` file does `export default { … }`; `index.js` deep-merges `common + city + city-static`
(or the climb trio) for the current page. Keys are dotted paths (`toast.cityTier`). One file per
app so parallel work never edits the same file.

Values:
- Plain strings use `{name}` placeholders. Strings carry their own non-breaking spaces (` `)
  where a number and its unit must not wrap (the share card wraps on plain spaces only).
- Functions receive the params object and return a string. Use them for grammar: gender, articles,
  word order. Pass whole objects (a City, a tier) so `pt-BR` can pick `a/o`, `da/do`, `na/no`.
- Plurals are objects `{ zero?, one, other }` of strings or functions, used through `plural()`.
- Catalog entries (tiers, monuments, badges, camps, belts, models, map modes, styles) are objects
  with explicit forms, never derived with `toLowerCase()`:
  `tier.city.metropolis = { name: 'Metropolis', a: 'a metropolis', lower: 'metropolis', plural: 'metropolises' }`.
- Word lists are arrays: `anon.animals` (35), `anon.adjectives` (15), `months` (12), `weekdays` (7).

`pt-BR/common.js` exports the article helpers used by the other pt-BR files:
```js
export const city = (c) => c.name ?? `Time ${c.code}`;
export const a  = (c) => (c.name ? `a ${c.name}` : `o ${city(c)}`);   // "a Plataforma" / "o Time 43FA"
export const A  = (c) => (c.name ? `A ${c.name}` : `O ${city(c)}`);
export const da = (c) => (c.name ? `da ${c.name}` : `do ${city(c)}`);
export const na = (c) => (c.name ? `na ${c.name}` : `no ${city(c)}`);
```

## Formatters (`public/i18n/fmt.js`)

Rule: instants (ms) are formatted in `config.timeZone`; ISO calendar days are formatted at UTC
noon so the day never shifts. Numbers never need the zone. All clocks are 24 h (`hourCycle: 'h23'`)
in every language.

| Function | en | pt-BR |
|---|---|---|
| `int(v)` | `12,345` | `12.345` |
| `dec(v, max = 1, min = 0)` | `1.5` | `1,5` |
| `percent(v01)` | `42%` | `42%` |
| `ordinal(n)` | `1st 2nd 3rd 4th` | `1º 2º 3º` |
| `list(arr)` | `a, b and c` | `a, b e c` |
| `collator.compare` | locale-aware sort | |
| `tokens(t, { short })` | `466.9 M`, `<0.01 M` (NBSP before the unit; millions scale always, never compact notation) | `466,9 mi` |
| `pace(t)` | `1.2 M/h` | `1,2 mi/h` |
| `meters(m)` | `3,484 m` | `3.484 m` |
| `date(ms, 'long' \| 'short')` | `Wednesday, October 21` / `Oct 21` | `quarta-feira, 21 de outubro` / `21 out` |
| `time(ms)` | `14:05` | `14:05` |
| `dateTime(ms)` | `Wed Oct 21 14:05` | `qua 21 out 14:05` (no trailing dots) |
| `clock(hourFloat)` | `14:05` | `14:05` |
| `isoDate(iso)` | `10/21/2026` | `21/10/2026` |
| `dayShort(iso)` | `Wed 10/21` | `qua 21/10` |
| `dayMonth(iso)` | `10/21` | `21/10` |
| `weekday(iso, 'long' \| 'short')` | `Wednesday` / `Wed` | `quarta` / `qua` |
| `monthName(m0, 'long' \| 'short')` | `November` / `Nov` | `novembro` / `nov` |
| `period(p, 'long' \| 'short')` | `Week 45, 2026` / `W45`; `November 2026` / `Nov` | `Semana 45/2026` / `S45`; `novembro de 2026` / `nov` |
| `duration({ d, h, m })` | `4d 07h`, `1h05`, `~15 min` | same |

`fmt` replaces the scattered formatters: `fmt` in panels, `fmtMi/meters/nf1/nf2/integer/dayShort/
ddmm/fmtPace/nb/two` in the climb, `longDate/time/plural` in rules, `dayLabel` in history, `corpos`
in scale, `clockLabel/spHour` in `lib/sky.js` (`spHour` becomes `zoneHour(timeZone)`).

## Frozen identifiers (JS ↔ HTML ↔ CSS ↔ docs)

### Catalog keys
| Catalog | Keys |
|---|---|
| City tiers (`CITY_TIERS`) | `village, town, capital, metropolis, megalopolis, globalCity, futureCity, marsColony` |
| Building tiers (`BUILDING_TIERS`) | `house, townhouse, poolHouse, condo, building, tower, skyscraper, supertower, cloudTower, orbitalTower, spaceElevator` |
| Monuments (`MONUMENTS`) | `obelisk, airport, stadium, ferrisWheel, centralPark, tvTower, leadershipStatue, fountainSquare` |
| Dojo levels (`DOJO_LEVELS`) | `dojo, temple, greatTemple` |
| Map modes (`MAPKEYS`) | `now, week, network, model, belts` (default view has no key) |
| Styles (`STYLE_PAL`) | `brick, concrete, glass, deco, neon` |
| Camps | `kind: base \| camp \| summit`, `n` 0..5 |
| Badges | `champion, summit, sherpa, streak, rocket, cache, marathon, surgical, chatty, rookie, stage` |
| Belts | `white, blue, purple, brown, black` |
| Models | `opus, sonnet, haiku, fable, other` |
| Sky phases (`lib/sky.js`) | internal, unchanged |

Tables keep their numeric rules and gain a `key`; display text comes from `t('tier.city.' + key)`,
`t('monument.' + key)`, etc. Any lookup keyed by a display name (`tiers[t.name]`, the `FEM` set)
switches to the key.

| Old | New |

### Pages
- `city.html` is hidden (`html { visibility: hidden }`) until `initI18n()` resolves, to avoid an
  English flash for pt-BR visitors. `climb.html` already shows `#loading`.
- The 🌐 switcher sits in the header of both pages: two buttons `EN` / `PT`, the active one
  marked with `aria-pressed`, calling `setLocale`.
- `<title>` is `t('page.title', { appName })`; headers show `config.appName` upper-cased.
